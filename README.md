# Dynamic Pricing Optimization

## Overview
This project predicts product prices and demand using Machine Learning.

## Features
- Exploratory Data Analysis
- Revenue Trend Analysis
- Demand Forecasting
- Price Prediction
- Product Segmentation
- Explainable AI (SHAP)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## Machine Learning Models
- Linear Regression
- Ridge Regression
- Random Forest
- XGBoost

## Dataset
Retail pricing dataset with:
- prices
- competitor prices
- quantity sold
- customer data

## Results
Best model:
- Linear Regression
- R² ≈ 1.0
- Very low MAE and RMSE
